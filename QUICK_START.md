## 🎯 Only ONE Thing You Need to Do:

### Add Your Photo!

1. Get a professional photo of yourself (headshot, clear background works best)
2. Save it in the same folder as these files
3. Name it: `profile.jpg`
4. Open `index.html` in a text editor (Notepad, VS Code, etc.)
5. Find line 58 (or search for "image-placeholder")
6. Replace this:
```html
<div class="image-placeholder">
    <i class="fas fa-user"></i>
</div>
```

With this:
```html
<img src="profile.jpg" alt="Somantha Manuranga" style="width: 350px; height: 350px; border-radius: 50%; object-fit: cover; box-shadow: 0 20px 60px rgba(59, 130, 246, 0.3);">
```
